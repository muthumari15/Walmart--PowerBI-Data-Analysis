# Walmart-PowerBI-Data Analysis

This project is based on Walmart data and includes my Power BI work on loading, cleaning, validating, and modeling the data. I worked on preparing the data, checking its quality and validity, creating relationships between tables, and organizing the data for analysis. This project helped me understand the basic steps involved in preparing real-world data and using Power BI for better data analysis and visualization.
